Квадратные уравнения: дискриминант и знаки корней

В тесте на уравнение x² − 5x + 6 = 0 ты уверенно ответила «−2 и −3». Числа угаданы верно, знаки — нет. Это самая частая ошибка в теореме Виета, и у неё есть простое объяснение.

Общий вид и универсальный способ

Квадратное уравнение — это ax² + bx + c = 0, где a ≠ 0. Работает всегда формула через дискриминант:

D = b² − 4ac

D > 0  →  два корня:  x = (−b ± √D) / 2a
D = 0  →  один корень: x = −b / 2a
D < 0  →  действительных корней нет

Проверим на нашем уравнении: a = 1, b = −5, c = 6.

D = (−5)² − 4·1·6 = 25 − 24 = 1
x = (5 ± 1) / 2  →  x₁ = 3,  x₂ = 2

Обрати внимание на −b: поскольку b = −5, то −b = +5. Именно здесь чаще всего и теряется знак.

Теорема Виета и её главная ловушка

Для приведённого уравнения x² + px + q = 0 (коэффициент при x² равен единице):

x₁ + x₂ = −p      ← сумма равна коэффициенту при x с ОБРАТНЫМ знаком
x₁ · x₂ = q       ← произведение равно свободному члену как есть

Вот тот самый минус, который съедается при устном счёте. Разберём наш случай:

x² − 5x + 6 = 0    здесь p = −5,  q = 6

сумма       = −p = −(−5) = +5
произведение = q  = 6

Ищем два числа, которые в сумме дают +5, а в произведении 6. Это 2 и 3.

Твой вариант −2 и −3 даёт произведение 6 (верно, минус на минус), но сумму −5 вместо +5. Он был бы правильным для уравнения x² + 5x + 6 = 0.

Проверка занимает пять секунд

Любой найденный корень можно подставить обратно:

x = −2:  (−2)² − 5·(−2) + 6 = 4 + 10 + 6 = 20 ≠ 0   ✗
x =  2:   2²  − 5· 2   + 6 = 4 − 10 + 6 =  0        ✓

Привычка подставлять снимает эту ошибку навсегда: неверный знак вылезает мгновенно.

Почему знак переворачивается: разложение на множители

Смысл минуса станет очевиден, если раскрыть скобки. Если корни x₁ и x₂, то

x² + px + q = (x − x₁)(x − x₂)

Раскрываем правую часть:

(x − x₁)(x − x₂) = x² − x₂x − x₁x + x₁x₂
                 = x² − (x₁ + x₂)·x + x₁x₂

Сравниваем с x² + px + q: получается p = −(x₁ + x₂) и q = x₁x₂. Минус живёт прямо в скобках вида (x − корень).

Отсюда практическое правило: корни имеют знак, противоположный тому, что стоит в скобках.

x² − 5x + 6 = (x − 2)(x − 3)   →  корни  2 и 3
x² + 5x + 6 = (x + 2)(x + 3)   →  корни −2 и −3

Определить знаки корней, не считая их

По знакам p и q можно сразу сказать, куда смотрят корни:

Произведение qСумма −pКорниПример
плюсплюсоба положительныеx² − 5x + 6 → 2, 3
плюсминусоба отрицательныеx² + 5x + 6 → −2, −3
минуслюбаяразных знаковx² − x − 6 → 3, −2

Логика простая: произведение положительно, когда знаки одинаковы, и отрицательно, когда разные. А общий знак пары задаёт сумма.

Что означает дискриминант на графике

График y = ax² + bx + c — парабола. Ветви смотрят вверх при a > 0 и вниз при a < 0. Корни уравнения — это точки пересечения с осью x, то есть места, где y = 0.

  • D > 0 — парабола пересекает ось в двух точках.
  • D = 0 — касается оси вершиной, корень один (говорят «двойной»).
  • D < 0 — висит целиком выше или ниже оси, пересечений нет.

Например, у x² + 2x + 5 дискриминант равен 4 − 20 = −16. Корней нет: парабола с ветвями вверх целиком лежит над осью. Это не ошибка в вычислениях, а законный ответ «действительных решений нет».

Когда коэффициент при x² не единица

Теорема Виета в приведённом виде требует a = 1. Если это не так, либо делят всё уравнение на a, либо пользуются общей формой:

2x² − 7x + 3 = 0

сумма       = −b/a = 7/2 = 3,5
произведение = c/a = 3/2 = 1,5
подбираем:  3 и 0,5     (3 + 0,5 = 3,5 ✓,  3 · 0,5 = 1,5 ✓)

Проверка через дискриминант: D = 49 − 24 = 25, корни (7 ± 5)/4, то есть 3 и 0,5. Совпало.

Что уносим с собой. D = b² − 4ac, корни (−b ± √D)/2a. По Виету сумма равна −p — с обратным знаком, а произведение равно q как есть. В разложении (x − x₁)(x − x₂) знак в скобках противоположен корню. Подстановка корня обратно ловит ошибку за пять секунд.
