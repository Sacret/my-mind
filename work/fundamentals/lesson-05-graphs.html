Графы: обходы BFS и DFS, кратчайший путь

Закрывает провал продвинутого теста: вопрос про кратчайший путь в графе с рёбрами одинакового веса. Граф — самая универсальная структура: карта дорог, социальная сеть, зависимости пакетов, состояния игры, ссылки между страницами. Как только видишь «объекты и связи между ними», это граф, и для него есть готовый набор алгоритмов.

Из чего состоит граф

Вершины (узлы) и рёбра (связи между ними). Рёбра бывают ненаправленными (дружба) и направленными (подписка, зависимость), а также взвешенными (расстояние, цена, время). Граф без циклов и с одной вершиной-корнем — это дерево; направленный граф без циклов — DAG, на нём строят порядок сборки и планировщики задач.

Хранят граф двумя способами:

ПредставлениеПамятьХорошо, когда
Список смежности (у каждой вершины — список соседей)O(V + E)граф разреженный: рёбер немного; почти всегда выбирают его
Матрица смежности (таблица V × V)O(V²)граф плотный или нужна мгновенная проверка «есть ли ребро»
const graph = {
  A: ["B", "C"],
  B: ["D"],
  C: ["D"],
  D: []
};

Обход в ширину (BFS)

Идёт «волнами»: сначала сама вершина, затем все её соседи, затем соседи соседей. Основа — очередь (первым пришёл — первым вышел) и множество посещённых.

function bfs(start) {
  const seen = new Set([start]);
  const queue = [start];
  while (queue.length) {
    const v = queue.shift();
    for (const next of graph[v]) {
      if (!seen.has(next)) { seen.add(next); queue.push(next); }
    }
  }
}

Ключевое свойство: BFS находит кратчайший путь по числу рёбер. Волны расходятся на одинаковое расстояние, поэтому вершина впервые встречается по кратчайшему пути. Если все рёбра равнозначны — лабиринт, «рукопожатия» в соцсети, минимальное число ходов — берёт именно BFS. Сложность O(V + E).

Обход в глубину (DFS)

Идёт «вглубь»: пока есть непосещённый сосед, шагает к нему, а упёршись в тупик — возвращается. Основа — стек (явный или стек вызовов рекурсии). Той же сложности, O(V + E), но отвечает на другие вопросы:

  • есть ли путь между двумя вершинами, сколько компонент связности;
  • есть ли в графе цикл (например, циклическая зависимость модулей);
  • топологическая сортировка — порядок, где каждая задача стоит после своих зависимостей.

Кратчайший путь DFS не гарантирует: он может найти длинный обходной путь раньше короткого.

Замечание про очередь. В JS Array.shift() сдвигает весь массив, то есть O(n), и большой BFS становится квадратичным. Для настоящих объёмов используют индекс головы очереди или отдельную структуру.

Кратчайший путь во взвешенном графе

Когда у рёбер разная цена, BFS не подходит: путь из трёх дешёвых рёбер лучше одного дорогого. Тут работает алгоритм Дейкстры: держит расстояния до вершин и каждый раз берёт ближайшую ещё не обработанную, обновляя ей соседей. Для быстрого выбора ближайшей нужна очередь с приоритетом (куча), сложность O((V + E) log V).

Ограничение: Дейкстра требует неотрицательных весов. При отрицательных применяют Беллмана — Форда. Для веб-навигации и карт используют A* — Дейкстру с подсказкой, куда двигаться.

Что выбрать

ЗадачаАлгоритм
Кратчайший путь, все рёбра одинаковыBFS
Кратчайший путь, у рёбер разные неотрицательные весаДейкстра
Найти цикл, порядок зависимостей, компонентыDFS
Что уносим с собой. Граф — вершины и рёбра; чаще всего его хранят списками смежности. BFS ходит волнами через очередь и находит кратчайший путь по числу рёбер. DFS идёт вглубь через стек и подходит для циклов, компонент и топологической сортировки. При разных неотрицательных весах нужен Дейкстра с кучей. Сложность обходов — O(V + E).
